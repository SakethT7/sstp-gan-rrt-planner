V7.7 RESULTS GALLERY

01_FIGURES contains numbered 300-DPI PNG and vector SVG figures.
02_FIGURE_DATA contains the exact CSV values plotted in every figure.
03_SUMMARY_TABLES contains long-format final metrics and raw rollout rows.
04_PATH_IMAGES contains real rerun planner images when requested.

Presentation formatting: percentages use two decimals; ordinary values use at most two decimals; small errors and losses use scientific notation. CSV and JSON source values retain full precision.

No value or path in this directory is fabricated.
