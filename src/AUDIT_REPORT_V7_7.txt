RUNTIME CHECK THAT MUST RUN IN THE USER'S PYTORCH ENVIRONMENT
-------------------------------------------------------------
This workspace does not contain PyTorch, so it cannot honestly execute the
neural forward/backward pass. The required preflight command runs that check in
the user's lqr_cbf_env before training. It verifies finite generator and
discriminator outputs, nonzero finite gradients, exact dynamics, arbitrary-
weight D4 equivariance, and obstacle-permutation invariance. Training must not
start unless preflight prints both MODEL SMOKE TEST PASSED and PREFLIGHT PASSED.

------------

leakage correctness. They do not fabricate or guarantee an unobserved 98%
validation result. The experiment must be run, and the deterministic validation
