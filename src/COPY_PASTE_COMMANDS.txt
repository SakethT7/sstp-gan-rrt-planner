Run these ONE AT A TIME in WSL. Do not paste terminal output back into WSL.

1. PREFLIGHT

2. START NEW TRAINING
bash "$HOME/V7_7_GENERALIZATION_SOURCE/v7_7.sh" train

3. CHECK STATUS AT ANY TIME
bash "$HOME/V7_7_GENERALIZATION_SOURCE/v7_7.sh" status

4. VIEW THE LIVE LOG (Ctrl+C only exits the viewer)
